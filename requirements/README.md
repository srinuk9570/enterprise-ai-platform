# Requirements Management

This directory contains requirement files for different environments.

## 📁 Files

| File | Purpose | Install Command |
|------|---------|-----------------|
| `base.txt` | Core dependencies for all environments | `pip install -r requirements/base.txt` |
| `dev.txt` | Development dependencies (includes base) | `pip install -r requirements/dev.txt` |
| `prod.txt` | Production dependencies (includes base) | `pip install -r requirements/prod.txt` |
| `test.txt` | Testing dependencies only | `pip install -r requirements/test.txt` |
| `optional.txt` | Optional features and integrations | `pip install -r requirements/optional.txt` |
| `constraints.txt` | Version constraints for pip resolver | Used automatically by pip |
| `frozen.txt` | Auto-generated frozen dependencies | Generated by `make freeze` |

## 🚀 Quick Start

### Development Environment
```bash
# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # On Windows: .venv\Scripts\activate

# Install development dependencies
pip install -r requirements/dev.txt

Production Environment
bash
# Install production dependencies only
pip install -r requirements/prod.txt
Testing Environment
bash
# Install base + test dependencies
pip install -r requirements/base.txt
pip install -r requirements/test.txt
📦 Managing Dependencies
Add a new dependency
Add package to appropriate .txt file

Run pip install -r requirements/dev.txt

Commit both the requirements file and the change

Upgrade dependencies
bash
# Check for outdated packages
make outdated

# Upgrade all dependencies
make upgrade-all

# Freeze current versions
make freeze
Check for security vulnerabilities
bash
make security
🔧 Using Constraints
To ensure reproducible builds, use constraints:

bash
pip install -r requirements/base.txt -c requirements/constraints.txt
📊 Dependency Tree
View the dependency tree:

bash
make tree
⚠️ Important Notes
Always use virtual environments

Test after upgrading dependencies

Keep constraints.txt updated with critical version pins

Run security checks before deploying to production

Consider using pip-tools for more advanced dependency management

🛠️ Using pip-tools (Optional)
Install pip-tools
bash
pip install pip-tools
Compile requirements
bash
# Compile base requirements
pip-compile requirements/base.in -o requirements/base.txt

# Compile dev requirements
pip-compile requirements/dev.in -o requirements/dev.txt

# Sync environment
pip-sync requirements/dev.txt
